# CodeAlpha - Unemployment Analysis with Python

## Project Overview
This project analyzes unemployment trends in India using Python. It explores unemployment rates across different regions, compares rural and urban unemployment, and examines changes during the COVID-19 period.

## Objectives
- Clean and preprocess unemployment data.
- Analyze unemployment trends over time.
- Study the impact of COVID-19 on unemployment.
- Compare unemployment rates across Indian regions.
- Analyze rural and urban unemployment rates.
- Visualize insights using Python libraries.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Information
- Original Records: 768
- Records after cleaning: 740
- Total Regions: 28
- Columns: 7
- Data Period: May 2019 – June 2020

## Key Findings

| Analysis | Result |
|---|---:|
| Overall Average Unemployment Rate | 11.79% |
| Before COVID | 9.51% |
| During COVID | 17.77% |
| Highest Unemployment Region | Tripura (28.35%) |
| Bihar Average Unemployment Rate | 18.92% |
| Rural Unemployment Rate | 10.32% |
| Urban Unemployment Rate | 13.17% |

## Visualizations
1. Unemployment Rate Trend in India (2019–2020)
2. COVID-19 Impact on Unemployment Rate
3. Top 10 Regions by Average Unemployment Rate
4. Rural vs Urban Unemployment Rate

## Conclusion
The analysis shows that unemployment rates increased considerably during the COVID-19 period in this dataset. Urban areas recorded a higher average unemployment rate than rural areas. Tripura had the highest average unemployment rate among the 28 regions analyzed.
